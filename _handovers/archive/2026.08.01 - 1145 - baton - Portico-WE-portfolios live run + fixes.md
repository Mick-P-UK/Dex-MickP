## Three fixes the live run surfaced (all permanent)
1. ViewTransactions (Mick's diagnosis): the routine did not open the Transactions view
   first, so select_portfolio could never confirm (empty header, both PPs failed). Added
   ensure_transactions_view() to sharescope_portico.py (clicks data-cmd=ViewTransactions
   after login, before the portfolio loop). Documented in ShareScope-data-cmd-Reference.md.
2. Windows font bug: annotate_portico.py's font() only knew the Linux DejaVu path, so on
   Windows it fell back to PIL's tiny fixed default and IGNORED all label sizes - that was
   why the labels looked wrong vs Mick's manual images. font() now finds Arial on Windows.
3. Tesseract path: pytesseract could not find the Windows Tesseract (installed but not on
   PATH). annotate_portico.py now points at C:\Program Files\Tesseract-OCR\tesseract.exe.
   (Label size was briefly over-enlarged then reverted to the original tuned multipliers
   once the font fix made sizes actually apply.)

## Notes

Notes for answering the member query on context window sizes. Figures
verified against Anthropic's own documentation on 2 August 2026 - these
change often, so worth re-checking before quoting them in future.

THE SHORT ANSWER
No, they are not all the same - but the size depends far more on which
MODEL you have selected than on which surface you are using.

1. CHATTING ON CLAUDE.AI OR THE MOBILE APP (paid plans)
- Opus 5 and Sonnet 5: 1M tokens
- Opus 4.8, Opus 4.7, Opus 4.6 and Sonnet 4.6: 500K tokens
- All other models: 200K tokens

2. CLAUDE CODE (Pro, Max, Team or Enterprise)
- Sonnet 5, Fable 5, Opus 5, Opus 4.8, Opus 4.7 and Opus 4.6: 1M tokens
- Pro users must enable usage credits to get the 1M window on the Opus
models
- Sonnet 4.6 also reaches 1M on all paid plans, again with usage credits
enabled (except on usage-based Enterprise plans)

3. CLAUDE COWORK
Anthropic does not publish a separate figure for Cowork. It runs the same
underlying models, so the same per-model windows apply.

Note: all of the above is for PAID plans. Free plan limits are not
published in the same way and can vary with demand.

TWO POINTS WORTH ADDING FOR THE MEMBER

Automatic context management. Where code execution is enabled, Claude now
summarises earlier messages as the conversation approaches the limit, so
most conversations can continue indefinitely. That summarising does not
count towards the usage limit.

Bigger is not automatically better. Anthropic's own documentation flags
"context rot" - as the token count grows, accuracy and recall degrade.
Curating what goes into the context matters as much as how much room there
is. In practice this means a disciplined handover or wrap partway through a
long thread still produces better output than simply letting a 1M window
fill up. Worth making that point rather than leaving the member with the
impression that a bigger number is a straight upgrade.

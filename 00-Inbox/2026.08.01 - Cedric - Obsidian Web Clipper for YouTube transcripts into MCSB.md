WHY THIS MATTERS
Web Clipper looks like a cheap route to get YouTube transcripts of
investing videos straight into Obsidian, and from there into MCSB. Worth
testing before building anything custom.

WHAT IT IS
Obsidian Web Clipper is a browser extension (Chrome/Firefox), not a vault
plugin. It clips a page into a markdown note using a template, with
configurable folder path and YAML properties. Different templates can write
to different folders, so video clips could land in their own inbox folder
separate from articles.

HOW THE YOUTUBE TRANSCRIPT BIT WORKS
- The community repo obsidian-community/web-clipper-templates has two
YouTube templates: a basic one (metadata only) and a "YouTube with
transcript" one.
- The transcript is pulled with a CSS selector off YouTube's transcript
panel.
- CRITICAL: the transcript panel must be open on the page BEFORE you clip.
Click "Show transcript" under the description first, or the transcript
section comes back empty.
- Only works on videos that have captions. No captions, no transcript.

KNOWN GOTCHA
YouTube changed its UI in February 2026 and broke the old templates - the
CSS selector is the same but the target-id changed. There is a fixed
template posted on the Obsidian forum: "Web Clipper YouTube video +
transcript (for YT's UI Feb 2026 update)". Grab that version rather than
the older repo one.

EXTRA
Web Clipper has an Interpreter feature that can run the clipped transcript
through an LLM at clip time to produce a summary or key points, driven by
URL-pattern templates. That could replace the copy-into-Claude step.

NEXT ACTIONS

2. Import the Feb 2026 fixed YouTube transcript template.
3. Test on one investing video - check the transcript actually captures and

4. Decide the target folder and whether clips feed the MCSB inbox directly.
5. If it works, test whether Interpreter can auto-generate takeaways at

## Notes

Question: can I converse with my assistant by voice rather than dictating
into a prompt box?
Short answer: yes for general conversation and connected tools, no for the
vault skills, and the two cannot currently be combined without a build.
Source: Claude Help Centre -
https://support.claude.com/en/articles/11101966-use-voice-mode
Checked: August 2026. Voice mode is still flagged beta, so expect this to
move.

=====================================================
WHAT EXISTS NATIVELY TODAY
=====================================================
Voice mode is a genuine two-way spoken conversation, not dictation. I
speak, it speaks back.

- Available on all plans (Free, Pro, Max, Team, Enterprise).
- Works on mobile (iOS and Android), Desktop and web, but built to work
best on the phone.
- Start it with the sound wave icon in the chat input. On web and Desktop
it is in the lower right of the chat window.
- Several preset voices to choose from. Changed under Settings > General >
Voice settings on web and Desktop.

Two listening modes:
- HANDS-FREE (default). Listens continuously, responds to natural pauses.
Best in a quiet room.
- PUSH-TO-TALK. Hold a button while speaking. Use this in noisy
environments or if it keeps interrupting.

Other points worth knowing:
- Can switch between text and voice inside the same conversation without
losing context. Useful for typing a URL or a ticker mid-conversation and
then carrying on by voice.
- Same models available as in text chat, and the model can be switched
mid-conversation. Claude Fable is not available in voice mode.
- Transcripts of voice conversations are saved to chat history like any
other chat.
- Voice conversations count against normal usage limits.
- Many languages supported (beta), set under Settings > General > Voice >
Language.

=====================================================
THE BIT THAT MATTERS FOR MY SETUP
=====================================================
GOOD NEWS: voice mode can use connected tools during a spoken conversation
- Gmail, Google Calendar, Google Docs, Slack. So the daily briefing use
case works by voice right now with no build at all. Ask it to check the
calendar or catch me up on email, out loud, hands busy.

THE CATCH: voice mode is NOT available in Claude Cowork or Claude Code.
Dictation is available in both, but voice mode is not. Explicitly, voice
mode cannot reference the projects and skills set up in Cowork.

So there is a split that cannot currently be straddled:

OPTION A - VOICE PLUS CONNECTORS, NO VAULT SKILLS
Native voice mode. Spoken both ways. Reaches calendar, email, docs, Slack,
web search.
Best for: morning briefings, diary questions, thinking out loud on a walk,
learning, capturing ideas away from the desk.

OPTION B - FULL SKILLS AND VAULT ACCESS, NO SPOKEN REPLIES
Desktop or Claude Code with dictation. I talk, it types, it answers in text.
Best for: anything touching the skills library, the vault, the Xero
conversions, portfolio work.

=====================================================
OPEN QUESTION TO TEST
=====================================================
Whether Desktop voice mode reaches the local MCP servers (Filesystem,
Notion, etc). The documentation is explicit that Cowork skills are out of
scope, but says nothing either way about Desktop MCP. Five minutes with the
microphone would settle it. Worth doing before assuming anything.

=====================================================
IF I WANT THE REAL THING
=====================================================
Genuinely conversational access to the full skill set is a build, not a
setting:
speech-to-text in -> Claude API with the skills and MCP wired up ->
text-to-speech out.
The PAIDA architecture is most of the way there already, so this is
plausible rather than fanciful, but it is a project. Park it until the
native feature has had another few months to mature - it is still beta and
moving quickly.

=====================================================
IMMEDIATE ACTIONS
=====================================================
1. Try native voice mode on the phone for one morning briefing and see
whether it is actually pleasant to use.
2. Test whether Desktop voice mode can see the local MCP servers.
3. Set the voice language and pick a voice under Settings > General.
4. Revisit the API build option only if 1 and 2 prove the gap is genuinely
blocking.

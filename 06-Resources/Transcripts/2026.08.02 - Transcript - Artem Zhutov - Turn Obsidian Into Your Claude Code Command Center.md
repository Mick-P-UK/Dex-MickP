## Summary

Artem Zhutov builds a dynamic Obsidian "command center" dashboard that both he and Claude
read each morning. Frustrated that plain markdown is too limited, he embeds HTML, CSS and
JavaScript inside an Obsidian note using the DataView plugin's inline JavaScript queries,
rendering live Bases views (focus goals with editable timelines, sleep and energy plots,
running experiments, personal citations, and a point A / point B life vision) that update
in real time as he edits his daily notes. The same command center JavaScript file is read
by Claude, which pulls the identical Bases data, so the human and the AI share exactly one
context. He frames this as "dynamic memory": goals and experiments sit on a timeline and,
once flipped from active to done, drop out of the view automatically, keeping the shared
context fresh without re-explaining it. He demos a 5-minute prototype and suggests turning
the morning read into a Claude skill.

## Key Takeaways

- Embed HTML/CSS/JS in an Obsidian note via DataView's inline JavaScript queries (enable
  both "inline JS queries" and "JS queries" in DataView settings) for richer dashboards.
- The dashboard renders live Bases views that update in real time from your daily notes.
- One shared "command center": Claude reads the same JS file and pulls the identical Bases
  data, so you and the AI look at the same context.
- "Dynamic memory": goals/experiments live on a timeline; flipping one active -> done
  removes it from view, so context stays current with no re-explaining.
- He suggests wrapping the morning read into a Claude skill for one-shot context loading.
- Inspired by Atharv's article on "the unreasonable expressiveness of HTML"; uses point A /
  point B documents plus personal citations for daily focus.
- Caveat: relies on DataView inline JS (arbitrary code running in your vault) - power-user.

## Summary

Chase demonstrates piping a Graphify knowledge graph into an Obsidian vault via
Claude Code. He downloads the Claude Code docs (171 pages, 145 documents), points Graphify
at them - it extracts 591 concept nodes and 685 connections grouped into 67 "communities"
- then uses Graphify's --obsidian flag to auto-generate a vault of 591 backlinked markdown
files, all driven by natural-language commands in Claude Code. He wires each bare node stub
to its source document, then moves the standalone vault into his main vault as a subfolder.
The payoff is that Claude Code can reason over the concept map (following connections, not
just grepping) rather than re-reading raw docs. He stresses controlling the "flood" of ~600
files with one of four integration strategies - standalone vault, quarantine subfolder,
selective harvest, or full redistribution - and recommends the quarantine subfolder so the
whole import is a one-click delete if it does not fit the wider system.

## Key Takeaways

- Graphify turns a document set into a concept knowledge graph: nodes are extracted
  concepts (not pages), joined by connections and grouped into "communities".
- Graphify's --obsidian flag auto-generates a vault - one backlinked markdown file per
  node (e.g. 591 files, 685 links) - all via natural-language commands in Claude Code.
- The value: Claude Code reasons over the concept map (it knows the connections and the
  "why"), not just keyword search over raw docs.
- Node stubs are bare, so wire each one to its source document so answers can drill into
  the original text.
- Four ways to handle the flood of files into a main vault: standalone vault, quarantine
  subfolder (recommended - one-click delete), selective harvest, or full redistribution.
- Keep deliberate control of what enters a curated "Claude OS" vault rather than dumping
  600 files in wholesale.
- Relevance to us: directly applicable if we ever graph a document set (RNS archives,
  research) into the vault; the quarantine-subfolder discipline matches our inbox/review
  approach.

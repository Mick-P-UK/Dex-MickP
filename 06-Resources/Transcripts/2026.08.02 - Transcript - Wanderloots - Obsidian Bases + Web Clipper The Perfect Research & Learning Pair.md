## Summary

Callum (Wanderloots) builds a "Sources Base" in Obsidian from scratch and connects it to
the Web Clipper so that captured sources organise themselves. The core idea is to combine
the capture step (Web Clipper) and the organise step (Bases) so you always know what you
captured and where it landed. His central trick is a dedicated "content type" property
(article, youtube, ai chat, paper, book) used as a single global base filter, rather than
tags, with a separate filtered view per type. He walks through Web Clipper templates,
dynamic property variables auto-filled from each page, template triggers (URL rules that
auto-select the right template per site), per-type target folders, the highlighter, cover
images, and a "processed" checkbox that turns the base into a review inbox. He covers
harder sources (PDFs via the Zotero integration) and finishes with Books base tips
(Goodreads cover URLs, a star-rating formula, read/not-read checkboxes). Note: the video
is August 2025 and Bases syntax has since moved on - verify at help.obsidian.md/bases.

## Key Takeaways

- Build the database (base) FIRST, then wire the capture (clipper) into it.
- Use a dedicated "content type" property as the global filter, values: article, youtube,
  ai chat, paper, book. Global filter = "file has property content type" (better than tags).
- Each content type gets its own duplicated view filtered by "content type is X", and its
  own target folder (e.g. sources/clippings/article, sources/clippings/youtube).
- Template triggers are URL rules so no template-picking at capture: "https://" is the
  default (article) template; "https://www.youtube.com/watch?v=" triggers the YouTube
  template; "notebooklm.google.com" the NotebookLM template; Perplexity / Consensus similar.
- Property variables auto-fill from the page: title, url, date, a schema-author variable and
  a schema-description variable for YouTube, and the og:image meta variable for the cover.
  Use the three-dots menu in the clipper to see the exact variables a page exposes.
- When the default title is generic (e.g. a NotebookLM chat), use a selector variable
  (selector:H1) to grab the real page heading.
- A "processed" checkbox property turns the Sources base into an inbox / review queue.
- PDFs: use the Zotero integration plugin (content type = paper).
- Books base: link a Goodreads cover URL, a star-rating formula, a read/not-read checkbox.
- Requires Obsidian 1.9.10+ (Bases is now core). Video is Aug 2025 - verify current syntax.
